# EasyGo-Pedometer 想走就走計步器 APP

離線優先、零廣告、支援本機 CSV 匯出與活動合規全螢幕截圖的 Android 計步器應用。

## 核心特色

- **無廣告、隱私零外洩**：無第三方廣告或追蹤 SDK，所有計步紀錄優先儲存在本機。
- **符合活動截圖需求**：首頁一鍵全螢幕截圖（含系統狀態列時間與電量）、明確顯示「年月日與星期幾」、當日累計步數與累積運動時間。
- **日 / 週 / 月 / 年四維度統計**：預設進入今日畫面，提供 24 小時累計折線面積圖及週／月／年長條圖。
- **本機 CSV 紀錄與軟刪除**：支援自動與手動匯出 UTF-8 CSV 檔案，內建軟刪除機制（可復原）與防 CSV 注入保護。
- **零花費架構**：Android 原生開發（Kotlin + Jetpack Compose）搭配 GitHub Actions CI/CD 免費自動化測試與建置 APK。
