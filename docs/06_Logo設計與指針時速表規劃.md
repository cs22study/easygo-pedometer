# Spoke 7 設計規劃：腳丫丫 EzGo Logo 與指針＋數位雙顯時速表（`v0.6.0`）

## 1. 測速模式精簡與級距調整

### 1.1 首頁入口副標優化
- 實測 `v0.5.2` 在 `1080x2160` 手機螢幕上，「`單車(60) · 汽車火車(150) · 高鐵(400)`」末尾會出現 `...` 截斷。
- **`v0.6.0` 精簡為**：**`單車 60 · 車 160 · 高鐵 400`**（字數精簡、節奏明快，保證單行完整顯示無省略號）。

### 1.2 三段交通工具模式（`SpeedMode`）規格調整
| 模式 | 按鈕顯示 | 儀表上限 (`maxScaleKmh`) | 刻度分段（主刻度） | 防瞬移上限 (`maxPlausibleKmh`) | 精度門檻 | 熱量計算 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| `BIKE` | **單車 (60)** | `60 km/h` | `0, 15, 30, 45, 60` | `120 km/h` | `35 m` | 計算騎乘 METs |
| `VEHICLE` | **車 (160)** | `160 km/h` | `0, 40, 80, 120, 160` | `220 km/h` | `65 m` | 乘車不計熱量 |
| `HSR` | **高鐵 (400)** | `400 km/h` | `0, 100, 200, 300, 400` | `450 km/h` | `65 m` | 乘車不計熱量 |

> **調整說明**：將原「汽車火車(150)」簡化為「**車(160)**」，涵蓋汽車高速巡航與台鐵自強號/普悠瑪/太魯閣號最高營運時速（`~130–150 km/h`），且 `0–160` 四等分刻度（`0 / 40 / 80 / 120 / 160`）更整齊易讀。

## 2. 實體指針＋數位數字雙顯儀表盤設計（`SpeedometerGauge`）

相較於 `v0.5.x` 僅有圓弧進度條與端點圓點，`v0.6.0` 升級為真正的「**汽車／高鐵跑車式雙顯儀表**」：

### 2.1 儀表盤視覺分層（由外而內）
1. **外環軌道與進度弧**：
   - 掃描角度：`135°`（左下）至 `405°`（右下），總掃描夾角 `270°`。
   - 底軌深炭灰 `#252B36`，動態進度弧依目前時速比例填滿亮黃色 `#FFD600`（高鐵高速區段如 `>= 250 km/h` 可輔以暖橘金 `#FF9800` 高亮提示）。
2. **主副刻度線與數字標籤**：
   - 共繪製 `40` 格副刻度（每 10 格 1 主刻度），主刻度加粗並於內側標註 **5 組整數刻度**（例：`單車` 為 `0, 15, 30, 45, 60`；`車` 為 `0, 40, 80, 120, 160`；`高鐵` 為 `0, 100, 200, 300, 400`）。
3. **動態實體指針（Analog Needle）**：
   - 使用 Compose `animateFloatAsState(targetValue = speedKmh, animationSpec = tween(450))` 讓指針在 GPS 每秒更新間平滑移動、不生硬跳動。
   - 由儀表中心圓軸（外圈亮黃 `#FFD600`、內芯純白 `#FFFFFF`）向對應角度射出漸細指針（尖端略過刻度內緣），搭配柔和陰影增加立體層次。
4. **數位數字顯示（Digital Readout）**：
   - 配置於圓心軸套下方（扇形缺口正中央，不與指針重疊）：
   - 超大粗體等寬數字（`tnum`，如 **`298.4`**，`44.sp` 亮黃粗體）＋ 單位 **`km/h`**（`15.sp`）。

## 3. 「腳丫丫 + EzGo」APP Logo 設計規範

### 3.1 視覺概念
- **品牌辨識要素**：
  1. **腳丫丫（Footprints）**：一左一右錯落向前的可愛運動風光腳丫圖案（含圓潤腳趾與足弓曲線，象徵「想走就走」的輕盈步伐）。
  2. **`EzGo` 字樣**：粗體幾何現代無襯線字體，採用高飽和**漸層彩色**（珊瑚橘紅 → 亮黃 → 翠綠 → 天空藍）增加活力與辨識度，確保在手機桌面 `48dp` 小圖示尺寸下依然一眼辨識。
- **配色方案**：與新版首頁「暗黑＋亮黃」視覺統一——深邃黑曜石底色（`#0B0E14` → `#1C2128`）搭配亮黃（`#FFD600`）腳丫丫與漸層彩色 `EzGo`。

### 3.2 Android 實作規格（確認定案後套用）
- **雙格式輸出**：
  1. **Android 8.0+ Adaptive Icon**（`mipmap-anydpi-v26/ic_launcher.xml`）：背景層 `#0B0E14` + 前景層安全區內（`66%` 中心安全範圍）繪製「腳丫丫 + EzGo」向量/高解析圖層，支援圓形、圓角矩形、水滴形等各廠牌桌面裁切。
  2. **Android 7.x 傳統 PNG 圖示**（`mipmap-mdpi` `48px` 至 `mipmap-xxxhdpi` `192px`）：預先渲染圓角方形透明底版本，確保 OPPO R11s Plus（Android 7.1.1）桌面與安裝器顯示清晰。
- **預覽圖檔**：
  - V2 漸層彩色字版（已定案並套用至 `v0.6.0`）：[ezgo_logo_proposal_rainbow.jpg](./assets/ezgo_logo_proposal_rainbow.jpg)
