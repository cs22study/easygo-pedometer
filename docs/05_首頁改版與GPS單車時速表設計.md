# Spoke 6：首頁暗黑亮黃改版與 GPS 單車時速表設計規格

## 1. 首頁改版設計（參考圖 2–4 極簡高對比風格）

### 1.1 視覺配色與字體原則
- **背景與卡片**：深邃暗黑底色（`#0D1117`）搭配深炭灰圓角卡片（`#1C1F26`），頂部導覽列維持高辨識深色（`#161B22`），完全無廣告。
- **核心文字色彩**：所有計步數據文字、標題與日期星期統一採用 **亮黃色（`#FFD600`）** 搭配 **粗體字（`FontWeight.Bold`）**，無論在戶外強光或夜間騎乘環境下皆一目了然。

### 1.2 首頁版面結構（嚴格聚焦 4 項核心資料 + 單車時速入口）
1. **頂部頁籤列**：`日` | `週` | `月` | `年` + **一鍵截圖相機鈕** + **`⋮` 選單**（匯出本機 CSV、同步 Google Fit / Health Connect、設定）。
2. **日期與星期標題**：`◀  2026年11月25日 週三  ▶`（亮黃粗體字，明確顯示年月日與星期幾）。
3. **4 張垂直數據卡片**（仿圖 3–4 卡片資訊層級，右側附精簡趨勢小圖）：
   - **卡片 1 — 今日步數**（週/月/年顯示該區間累計步數）：大字粗體亮黃數字 +「步」。
   - **卡片 2 — 累計時間**：換算或偵測手機擺動運動之 **`時:分:秒`（`HH:MM:SS`）**，粗體亮黃數字。
   - **卡片 3 — 換算距離**：**`公尺`**（或依設定顯示公里），粗體亮黃數字。
   - **卡片 4 — 燃燒熱量**：**`千卡`**，粗體亮黃數字。
4. **下方功能按鈕**：於剩餘空間配置明顯的 **`GPS 單車時速表`** 按鈕，點擊進入專用騎乘儀表頁面。

## 2. GPS 即時時速表（支援單車 / 汽車火車 / 高鐵三段上限）

### 2.1 技術架構與隱私原則
- **原生離線定位**：採用 Android 原生 `LocationManager.GPS_PROVIDER`（不依賴雲端服務、免 Google Play Services、不申請 `INTERNET` 權限），座標僅於本機記憶體即時運算，絕不外傳（落實原則 2）。
- **騎乘防熄屏**：進入 GPS 時速表頁面時自動啟用 `FLAG_KEEP_SCREEN_ON`，離開頁面即自動釋放。
- **支援活動截圖**：時速表頁面頂部同步顯示今日日期星期與 **一鍵截圖按鈕**，方便完成單車「距離型 15 公里 / 時間型 30 分鐘」任務後直接截圖存檔。

### 2.2 頁面配置與三段測速上限切換
1. **頂部列**：`< 返回`、`2026年11月25日 週三`、一鍵截圖鈕。
2. **三段交通工具模式切換（`SpeedMode`）**：
   - **`單車 (60)`**：儀表上限 `60 km/h`，防瞬移上限 `120 km/h`，精度門檻 `35 m`，累計騎乘 METs 熱量。
   - **`汽車火車 (150)`**：儀表上限 `150 km/h`，防瞬移上限 `220 km/h`，精度門檻 `65 m`，乘車不計熱量。
   - **`高鐵 (400)`**：儀表上限 `400 km/h`（適配台灣高鐵 ~300 km/h），防瞬移上限 `450 km/h`，精度門檻 `65 m`，乘車不計熱量。
3. **中央弧形指針時速儀表盤**：動態顯示 `0`、中間值與上限刻度標籤 + 超大亮黃粗體即時時速（`km/h`）。
4. **2x2 行程數據格**（亮黃粗體數字）：行程時間（`HH:MM:SS`）、移動距離（公尺/公里）、平均/最高時速（`km/h`）、燃燒熱量（`千卡`）。
5. **底部控制列**：`開始測速` / `暫停測速` 與 `歸零` 按鈕。

## 3. 永久簽章機制（解決覆蓋安裝「未完成安裝」問題）

- **原因**：先前 GitHub Actions 每次執行皆重新產生隨機 `debug.keystore`，導致新舊版簽章憑證不一致，Android 系統禁止直接覆蓋升級。
- **解法**：
  - 於本機產生持久化簽章金鑰（置於 `.gitignore` 忽略之 `keystore/` 目錄，絕不外洩至 Git）。
  - `app/build.gradle.kts` 優先讀取 CI 環境變數（`ANDROID_KEYSTORE_PATH` / `PASS` / `ALIAS`）或本機 `keystore/keystore.properties`，啟用 v1 + v2 雙重永久簽章；CI 端搭配 GitHub Repository Secrets 還原同一把金鑰，確保後續每次更新皆可直接覆蓋安裝並完整保留歷史步數資料庫。

## 4. Android 7.1.1 / ColorOS 3.2 舊機相容性強化（`v0.5.1`）

針對 OPPO R11s Plus（Snapdragon 660 / Android 7.1.1 / ColorOS 3.2）實測安裝卡住問題，進行以下封裝強化：
1. **傳統函式庫解壓封裝**：設定 `jniLibs.useLegacyPackaging = true`，於 Manifest 啟用 `android:extractNativeLibs="true"`，避免舊版 ColorOS 套件安裝器掛載未壓縮 `.so` 時卡死。
2. **移除 ProfileInstaller 元件**：透過 Gradle 排除 `androidx.profileinstaller` 並停用 `ArtProfile` 任務，防止舊版 `PackageInstaller` 觸發不相容組件。
3. **停用資源路徑縮短優化**：於 `gradle.properties` 設定 `android.enableResourceOptimizations=false`，維持標準資源表結構相容 2017 年舊機。

### 2.3 GPS 速度與防飄移計算原理（`GpsRideCalculator`）
- **即時速度來源**：優先取衛星都卜勒速度 `speedMps * 3.6`；若無則以兩點 **Haversine 球面距離公式** $\Delta d / \Delta t$ 計算。
- **靜止飄移過濾**：
  - 若單點水平精度 `accuracyMeters > 35 m`，視為弱訊號飄移，不計入距離與極速。
  - 若速度 `< 1.5 km/h`（停等紅燈），速度顯示歸零為 `0.0 km/h` 且不累加靜止飄移距離。
- **單車 METs 熱量**：
  - $v < 16\text{ km/h} \rightarrow 4.0\text{ METs}$；$16 \le v < 19\text{ km/h} \rightarrow 6.8\text{ METs}$；$19 \le v < 22\text{ km/h} \rightarrow 8.0\text{ METs}$；$v \ge 22\text{ km/h} \rightarrow 10.0\text{ METs}$。
  - $\text{Calories} = \text{MET}(v) \times W(\text{kg}) \times \text{騎乘小時} \times 1.05$。
